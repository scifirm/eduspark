# EduSpark

> Activity-based science learning platform

EduSpark is an interactive web application designed to make science education engaging, accessible, and fun. Through hands-on activities and interactive simulations, students can explore scientific concepts and develop a deeper understanding of the world around them.

## 🎯 Project Description

EduSpark is a modern science learning platform built with React and Vite. It provides educators and students with an interactive environment to explore science through practical, activity-based learning. The platform emphasizes experiential learning, allowing students to conduct virtual experiments, visualize complex concepts, and track their progress.

## ✨ Features

- **Interactive Activities**: Hands-on science experiments and simulations
- **Visual Learning**: Rich visualizations to help understand complex scientific concepts
- **Progress Tracking**: Monitor learning progress and achievements
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Fast Performance**: Built with modern tools (React + Vite) for optimal speed
- **Accessible**: Inclusive design for all learners

## 🎓 Use Cases

- **Classroom Learning**: Teachers can integrate activities into their curriculum
- **Self-Paced Learning**: Students can explore topics independently
- **STEM Engagement**: Make science, technology, engineering, and math subjects engaging
- **Remote Education**: Fully accessible online for distance learning
- **Supplementary Learning**: Complement traditional textbooks with interactive content

## 📋 Prerequisites

- Node.js 16+ and npm or yarn
- Modern web browser with JavaScript enabled

## 🚀 Getting Started

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/scifirm/eduspark.git
   cd eduspark
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```
   or
   ```bash
   yarn install
   ```

### Development

Run the development server with hot module reloading (HMR):

```bash
npm run dev
```

The application will start at `http://localhost:5173` and automatically refresh as you make changes.

### Building for Production

Create an optimized production build:

```bash
npm run build
```

The built files will be in the `dist/` directory.

### Preview Production Build

Test the production build locally:

```bash
npm run preview
```

### Linting

Check code quality and style:

```bash
npm run lint
```
